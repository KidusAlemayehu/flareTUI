# Universal Command Palette

Press `Ctrl+P` anywhere to open the fuzzy command palette.

## Search Mechanics

Powered by `nucleo-matcher`, the same fuzzy matching engine used in modern terminal editors:
- Real-time character highlighting.
- Match score sorting based on prefix, camel-case, and word boundaries.

## Category Filters

Use `Tab` and `Shift+Tab` to cycle categories:
- `All`
- `Navigation`
- `Cloudflare`
- `Security`
- `Storage`
- `Workers`
- `Profiles`
- `System`
