# View 6: Security & WAF

Gain immediate threat intelligence and manage edge firewall rules with zero latency.

## Sub-Tabs

- **Events**: Real-time log of firewall triggers, challenges, and blocks.
- **WAF Rules**: List of active and paused rules with expressions and action targets.
- **Analytics & Threats**: Threat score gauge (0-100), activity timeline sparkline, and breakdown by origin country and ASN.

## Rule Operations

- `Space` or `t`: Toggle rule between Active and Disabled.
- `+` / `-`: Reorder rule priority in the execution pipeline.
- `f`: Cycle action filters (`ALL`, `BLOCK`, `MANAGED_CHALLENGE`, `JS_CHALLENGE`, `RATE_LIMIT`, `LOG`).
- `Enter` or `i`: Inspect event details, copy Ray ID (`r`), or copy Client IP (`c`).
