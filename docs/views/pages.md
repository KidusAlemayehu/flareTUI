# View 3: Cloudflare Pages

Manage Cloudflare Pages projects, preview branches, and production deployments without leaving the terminal.

## Features

- **Project Explorer**: View production domains, build configurations, and framework presets.
- **Deployments Modal (`d`)**: Review previous builds, commit hashes, authors, and deployment environments (Preview vs Production).
- **Build Logs (`l`)**: Stream historical or live build stage outputs.
- **Instant Rollback (`b`)**: Roll back production traffic to any previous successful deployment with safety confirmation.
