# Theme Customization

flareTUI includes multiple built-in color palettes.

## Switching Themes

Open the Command Palette (`Ctrl+P`) and type `Theme`:
- **Theme: Cloudflare Dark** (Signature orange and dark navy)
- **Theme: Catppuccin Mocha** (Modern pastel palette)
- **Theme: Tokyo Night** (Vibrant cyber-aesthetic)
- **Theme: Nord** (Clean Scandinavian arctic colors)

Selected themes persist in `~/.config/flaretui/config.toml`.
